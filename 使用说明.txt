小电视投屏 · 便携包使用说明
==============================

这个包是免安装的，解压到任意目录即可（建议不要放桌面，放 D 盘之类的固定位置）。

第一次使用，按顺序做两件事
--------------------------

【第 1 步】双击「1.启动桥接.bat」
  出现一个黑色命令行窗口，显示 "监听 http://127.0.0.1:8787" 就是成功了。
  这个窗口要一直保持开着，投屏全靠它。
  （包里自带了 Node 运行时，不需要单独安装任何软件。）

【第 2 步】双击「2.安装到浏览器.bat」
  它会自动把扩展复制好并打开浏览器的扩展管理页。
  然后在浏览器里点三下：
    1. 右上角打开「开发者模式」开关
    2. 点「加载已解压的扩展程序」
    3. 选中弹出的那个文件夹（C:\Users\你的用户名\AppData\Local\BiliTVCast\extension）

  完成后工具栏会出现一个粉色小电视图标。

怎么投屏
--------

1. 电视上打开「云视听小电视」App，确认电视和这台电脑连的是同一个路由器
2. 电脑浏览器打开任意 B 站视频页
3. 点工具栏的小电视图标 → 等它搜到电视 → 点「投屏到电视」
4. 电视开始播放

第二次打开扩展面板时会直接用上次的电视（秒开，不再重新扫描）。
想重新找一遍电视，点面板里的「重新搜索」。

网页悬浮球（一键投屏）
----------------------

装好扩展后，B 站视频页右下角会出现一个粉色悬浮球：

- 点一下 = 直接把当前视频投到「上次投屏的那台电视」，
  清晰度、弹幕设置都沿用扩展面板里保存的参数，从当前播放进度继续
- 投屏中球会变成深色，上方显示「播放中 03:21 / 12:00」这样的进度，
  这时再点一下 = 停止投屏
- 播放器进入全屏 / 网页全屏时悬浮球自动隐藏，退出全屏后回来
- 鼠标移到球上会浮现「×」，点它可以隐藏悬浮球；
  想再打开，到扩展面板里把「网页悬浮球」切回「显示」即可
- 第一次用（还没投过屏）点球会提示先到面板里搜一次电视，选一次就行

注意：悬浮球不显示投屏进度细节、也不能切清晰度/暂停，
需要精细控制时还是点扩展图标打开面板。

投屏面板上的两个开关
--------------------

【清晰度】投屏后状态卡里会出现「清晰度」下拉框，可以边播边切，切完会从当前
         进度继续播（不用重新拖进度条）。可选项由 B 站接口返回：
           未登录浏览器  → 高清 720P / 流畅 360P
           浏览器已登录  → 可能多出 1080P 之类（取决于账号与视频本身）
         切换是「电脑重新拉一条流再递给电视」，所以会有 1~3 秒黑屏，正常。

【弹幕】  默认「电视自己渲染」：弹幕由电视 App 按视频自带的弹幕池播放，
         画面最干净，不会重复也不会带框。
         如果电视上一条弹幕都没有，改选「电脑逐条推送」。
         选「关闭弹幕」则完全不放弹幕。

关于清晰度与登录
----------------

投屏由电脑拉好播放地址再推给电视（电视端自己拉流会被 B 站拒绝，这就是
「加载失败（错误码：null）」的根本原因，已绕过）。

浏览器里登录了 B 站账号时，扩展会把登录凭证交给桥接，优先去要 1080P 的流；
如果 B 站返回的是加密代理地址（电视播不了），会自动退回 720P —— 日志里会写
「已切换到兼容线路」，属于正常的自动降级，不是故障。

搜不到电视怎么办（重点看这里）
------------------------------

搜索逻辑已经改成：每块网卡分别发多播 + 同时扫一遍子网 9958 端口，
所以「装了 VPN / ZeroTier / 虚拟机网卡就搜不到」这类问题已经处理掉了。

如果还是搜不到，按顺序排查：

1. 电视没开「云视听小电视」App，或者电视在待机
   → 先把电视上的 App 打开，停在首页，再点搜索

2. 电视和电脑不在同一个网络
   → 电脑上看 IP：命令行敲 ipconfig
   → 电视上看：设置 → 网络 → 查看 IP
   → 前三段数字要一样（比如都是 192.168.131.x）才行
   → 电视连光猫的 WiFi、电脑插路由器的网口，这就不算同一个网

3. 路由器开了「AP 隔离 / 客户端隔离」
   → 这选项会让同一 WiFi 下的设备互相看不见，去路由器后台关掉

4. 手动添加（最稳）
   → 扩展面板底部有「手动添加」，直接填电视 IP，格式 192.168.131.135:9958
   → 端口固定 9958，填完点添加，能连上就会出现在设备列表里

5. 电脑装了杀毒 / 防火墙软件（火绒、360 等）
   → 把包里的 node\node.exe 加进白名单

注意
----

- 每次投屏前都要确保「1.启动桥接.bat」的窗口开着（开机后双击一次即可）
- 新版桥接会自己检查 8787 端口：如果发现上次的黑窗口还开着（旧版本占着端口），
  会先把它结束掉再启动，不会再出现「端口被占用」导致仍用旧代码的情况。
  启动时窗口里会打印「版本 1.3.0」，看不到这行说明跑的还是旧文件。
- 扩展管理页里这个扩展如果显示「已停用」，手动打开开关即可
- 以后如果更新了 extension 里的文件：先重跑一遍「2.安装到浏览器.bat」，
  再到浏览器的扩展管理页（chrome://extensions）点这个扩展上的「重新加载」按钮，
  然后重新打开视频页，否则浏览器用的还是旧代码
- 别把解压出来的文件夹删掉或移走，浏览器会一直引用它
- 桌面上如果还有一个单独的「启动桥接.bat」（不在这个文件夹里），那是旧版本，
  要求电脑里已安装 Node.js，不要用它，用文件夹里的「1.启动桥接.bat」
- 电视上出现「加载失败」时，先看桥接黑窗口的最后几行：
    「播放地址已就绪」  → 地址拿到了，失败多半是电视网络不通（电视要能上网）
    「已切换到兼容线路」→ 说明高清晰度地址电视不认，已自动降级，能播就不用管
- 有问题先看原项目里的 README.md
